Impulse Wave Checklist

Jesse and Jenna · Tier B — concise note manual intermediate

One-page decision checklist for confirming or invalidating an Elliott 5-wave impulse count as each wave unfolds.

Summary

A single-page flowchart/checklist (“C or E” — corrective or extension) for validating an Elliott Wave 5-wave impulse count in a bull market as it develops, wave by wave. For each of the five waves it lists what to expect (number of sub-waves), what invalidates the count, and channel-drawing guidance for projecting the next wave’s target.

Key points

  • Wave 1 and Wave 3 should each subdivide into 5 sub-waves; Wave 5 usually does too, unless it forms a diagonal triangle.
  • Waves 2 and 4 are corrective; refer to a companion correction table (not included in this document) to judge whether the correction is complete.
  • Wave 2 must not exceed (retrace past) the start of Wave 1; if it does, the prior trend is assumed to continue instead.
  • After Wave 2 completes, draw a parallel channel from Wave 0 through Wave 2 (anchored at Wave 1) to project a Wave 3 target.
  • Wave 3 must be a 5-wave move and its price range is usually greater than Wave 1; if Wave 3 is shorter than Wave 1, be alert that it may actually be a wave C, and check whether it exceeds 1.618x Wave 1 (if not, expect Wave 5 to extend).
  • After Wave 3 completes, draw a parallel channel from Wave 1 through Wave 3 (anchored at Wave 2) to project a Wave 4 target.
  • Wave 4 cannot enter the price territory of Wave 1; if it does, the “Wave 3” was likely actually Wave 3-of-a-larger-3, i.e., relabel and treat the current leg as Wave 2 of 3.
  • Wave 3 can never be the shortest of waves 1, 3 and 5; if Wave 3 extended past 1.618x Wave 1, Wave 5 tends to resemble Wave 1 in size, and if Wave 4 retraces more than 50% of Wave 3, watch for a Wave 5 failure (truncation).

Actionable rules

  1. Confirm each wave subdivides as expected (5 sub-waves for 1, 3, 5; corrective structure for 2, 4) before trusting the count.
  2. Invalidate the count and revert to “prior trend resumption” if Wave 2 breaks below the start of Wave 1.
  3. Invalidate/relabel the count if Wave 4 overlaps into Wave 1’s price territory (non-diagonal case).
  4. Use the 1.618x extension of Wave 1 as the threshold for judging whether Wave 3 is “extended” and what that implies for Wave 5’s likely size.
  5. Watch for a Wave 5 failure when Wave 4’s retracement of Wave 3 exceeds 50%.

Caveats

This is a bare checklist stripped from a larger course or book, referencing an external “Correction Table” that is not included, so several branches (“refer back to correction table”) cannot be followed from this document alone. No bear-market mirror version, no actual chart examples, and no source or date given for the material.

Who it is for

Traders already familiar with Elliott Wave basics who want a quick on-chart validity checklist for confirming an impulse count in real time.
